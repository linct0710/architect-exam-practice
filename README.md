# 築夢試室｜建築師考古題練習站

這是依照上一層 `113`、`114` 年資料夾建立的本機靜態網站。

## 開啟方式

直接雙擊 `index.html` 即可使用；它會導向互動作答頁 `quiz.html`。網站不需要安裝套件或連接資料庫。

## 功能

- 依年度篩選 113、114 年考古題
- 依科目名稱搜尋
- 將試卷拆成逐題互動作答
- 選項題可直接選 A、B、C、D，完成後自動比對官方答案
- 顯示答對、答錯、未作答、完成率與總分
- 可回顧每一題、查看自己的答案與正解並重新作答
- 申論／設計題提供作答文字區與「標記本題完成」自評模式
- 響應式版面，支援桌機與手機瀏覽
- 顯示模式切換按鈕

網站檔案：`index.html`、`quiz.html`、`quiz.css`、`quiz-app.js`、`questions-data.js`。

`questions.json` 與 `tools/generate_question_data.py` 是題庫資料與重新解析工具；如果日後新增年度 PDF，可重新執行解析工具後更新互動題庫。
